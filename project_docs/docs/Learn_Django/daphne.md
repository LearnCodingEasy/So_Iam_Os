# SO_IAM_OS — Daphne

## 1. تعريف المعرفة

**Daphne** هو خادم ASGI يتم تثبيته داخل بيئة Python الخاصة بمشروع **SO_IAM_OS**.

---

## 2. تثبيت Daphne

يتم تثبيت المكتبة باستخدام:

```cmd
pip install daphne
```

---

## 3. مكان التثبيت

يجب تنفيذ الأمر داخل بيئة Python الافتراضية الخاصة بالمشروع:

```text
(venv)
```

مثال:

```cmd
(venv) D:\So_Iam_Os\backend_django>pip install daphne
```

---

## 4. دور Daphne في المشروع

المعلومة المتوفرة في المصدر تحدد **تثبيت Daphne فقط**:

```cmd
pip install daphne
```

ولا يحدد المصدر هنا إعدادًا إضافيًا لـ Daphne أو طريقة تشغيله أو ربطه مع `ASGI_APPLICATION`.

لذلك لا يتم اعتبار أي إعدادات أخرى جزءًا من هذه المعرفة إلا بعد إضافتها إلى معرفة المشروع بشكل صريح.

---

## 5. حالة المعرفة

```text
Daphne
  ↓
pip install daphne
  ↓
متاح داخل بيئة المشروع
```

**الحالة:** تم تحديد وتوثيق خطوة تثبيت Daphne فقط.
