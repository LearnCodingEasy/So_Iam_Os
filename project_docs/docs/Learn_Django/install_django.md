# 🐍 Django

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

Django هو إطار عمل مبني باستخدام Python، وبيستخدم لبناء تطبيقات الويب والـ Backend والـ APIs بطريقة منظمة وقابلة للتوسع.

</div>

---

### 1. 🎯 Purpose

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

الهدف من Django هو توفير Framework جاهز يساعدنا في بناء الـ Backend بدل ما نضطر نبني كل مكون من الصفر.

في مشروع So_Iam_OS، Django هو الـ Framework الأساسي المسؤول عن الـ Backend.

</div>

---

### 2. 🧠 Concept

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

Django مبني باستخدام Python، وبيوفر لنا مجموعة من الأدوات والمكونات الجاهزة لبناء تطبيقات ويب متكاملة.

</div>

```text
Python
   ↓
Django
   ↓
Backend
   ↓
Django Project
   ↓
Django Apps
```

---

### 3. 🔧 Requirements

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

قبل تثبيت Django، لازم يكون Python وpip موجودين، ويفضل تشغيل الـ Virtual Environment الخاصة بالمشروع.

</div>

```cmd
python --version
```

```cmd
pip --version
```

### 4. 🛠️ Installation / Setup

#### 🔧 Install Django

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

لتثبيت Django داخل البيئة الافتراضية الحالية:

</div>

```cmd
pip install django
```

---

#### 🦄 Version

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

لمعرفة إصدار Django المثبت حاليًا:

</div>

```cmd
python -m django --version
```

### 📦 Upgrade

###### 📦 Upgrade Django ( If Necessary )

```
pip install -U Django
```

### 5. 🚀 Usage

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

### 6. 📁 Structure

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

```text

```

### 10. 🧠 Why?

<div dir="rtl" style="font-size: 1.3rem; font-weight: bold;">

بنستخدم Virtual Environment علشان نعزل مكتبات المشروع عن باقي مشاريع Python الموجودة على الجهاز.

وبنستخدم Django لأنه يوفر لنا بنية وأدوات جاهزة لبناء Backend منظم وقابل للتوسع.
