## Scope and interpretation

Static inventory of declarations in backend `urls.py` files. It records the exact path/prefix expression and target expression from each source declaration. It does not expand DRF routers into HTTP methods, include `@action` expansions as standalone endpoint rows, resolve every include into a runtime URL, infer serializers or payload schemas, or prove that requests succeed. Existing per-app API guides under `Build/complete_project_documentation/backend/` remain the detailed source references and identify additional contract gaps.
