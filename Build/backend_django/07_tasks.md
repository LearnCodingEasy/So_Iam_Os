# tasks

## تعريف التطبيق

`tasks` هو التطبيق المسؤول عن إدارة الأعمال والإجراءات التي يجب على المستخدم تنفيذها.

## الوظيفة الأساسية

يدير:

- إنشاء المهام.
- تعديل المهام.
- حالة المهمة.
- الأولوية.
- الموعد.
- المهام المرتبطة بالمشاريع.
- المهام المرتبطة بالأهداف.
- المهام الناتجة عن خطط التعلم.
- متابعة تنفيذ المهام.

## علاقته بـ So_Iam_OS

الـ Goals تحدد:

"إلى أين أريد أن أصل؟"

والـ Projects تحدد:

"ماذا أبني؟"

أما Tasks فتحدد:

"ماذا يجب أن أفعل؟"

لذلك يمثل التطبيق طبقة التنفيذ اليومية.

## ماذا يضيف عند الانتهاء منه؟

عند الانتهاء منه يصبح النظام قادرًا على تحويل الخطط والأهداف إلى Actions عملية.

Goal → Project → Task → Execution
