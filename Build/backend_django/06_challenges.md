# challenges

## تعريف التطبيق

`challenges` هو التطبيق المسؤول عن تسجيل وإدارة التحديات والمشكلات والعوائق التي تواجه المستخدم أثناء العمل والتعلم وتحقيق الأهداف.

## الوظيفة الأساسية

يدير:

- المشكلات.
- العقبات.
- نقاط الضعف.
- أسباب التعطل.
- التحديات المرتبطة بالمشاريع.
- التحديات المرتبطة بالتعلم.
- التحديات المرتبطة بالأهداف.
- حالة كل Challenge.
- الحلول أو المحاولات المرتبطة به.

## علاقته بـ So_Iam_OS

النظام لا يجب أن يعرف فقط:

"ماذا أريد؟"

بل يجب أن يعرف أيضًا:

"ما الذي يمنعني من الوصول إليه؟"

لذلك يستطيع AI مستقبلًا استخدام بيانات Challenges في التحليل والتخطيط واقتراح الحلول.

## ماذا يضيف عند الانتهاء منه؟

عند الانتهاء منه يبدأ So_Iam_OS في فهم المشاكل التي أواجهها، وليس فقط تسجيل الأنشطة التي أقوم بها.

وهذا يمهد لفكرة:

Problem → Analysis → Solution → Result → Learning
