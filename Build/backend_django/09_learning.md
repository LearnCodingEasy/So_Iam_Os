# learning

## تعريف التطبيق

`learning` هو نظام التعلم الشخصي داخل So_Iam_OS.

هدفه متابعة رحلة المستخدم التعليمية وربط التعلم بالتطبيق العملي والنتائج.

## الوظيفة الأساسية

يتابع:

- ما الذي أتعلمه.
- لماذا أتعلمه.
- مستوى المستخدم.
- المهارات المطلوبة.
- الدروس والمصادر.
- الممارسة.
- الاختبارات.
- التقييم.
- نقاط الضعف.
- مستوى التقدم.
- تطبيق المعرفة في المشاريع.

## علاقته بـ So_Iam_OS

التعلم داخل So_Iam_OS ليس مجرد مشاهدة محتوى.

الفلسفة هي:

Learn → Practice → Test → Evaluate → Advance

ثم:

Learning → Projects → Results

لذلك يرتبط `learning` مع:

Knowledge
Projects
Challenges
Goals
Tasks
AI
Memory

## ماذا يضيف عند الانتهاء منه؟

عند الانتهاء منه يصبح النظام قادرًا على معرفة:

"ماذا أتعلم؟"

"ماذا أعرف؟"

"ماذا لا أعرف؟"

"هل أستطيع استخدام ما تعلمته؟"

وبالتالي يستطيع AI اقتراح مسارات تعلم أكثر ارتباطًا بأهداف المستخدم الحقيقية.
